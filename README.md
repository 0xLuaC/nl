# nl

## Расшифровка module.bin

модуль зашифрован AES-128-CBC с паддингом PKCS#7, поверх стоит сжатие LZ4 block

### Ключ

- Ключ (16 байт, HEX): 643831562A4B0F652559061470494A7D
- IV (16 байт, ASCII): 5aAxpFpna5QqvYMv

### Шаги расшифровки

1. AES-128-CBC decrypt всего файла ключом и IV выше
2. Снять PKCS#7 паддинг
3. Первые 4 байта результата это размер несжатых данных (uint32, little-endian)
4. Остаток распаковать LZ4 block
5. FlatBuffer на выходе
